Setup Free Gemini API Key

Clearpostersai uses your own Google Gemini API key to render artwork directly in your browser.

1
Go to Google AI Studio to access key creation. OPEN GOOGLE AI STUDIO
2
Click the "Create API Key" button inside Google AI Studio.
3
Select "Create API key in new project" (or choose an existing project).
4
Copy your generated key (starts with AQ.Ab... or AQ...) and paste it below.
🔒 Strict Privacy Clarification: Your API key is saved strictly inside your browser's local storage (localStorage). It never leaves your browser, never goes to external servers, and is only sent directly to official Google API endpoints.
